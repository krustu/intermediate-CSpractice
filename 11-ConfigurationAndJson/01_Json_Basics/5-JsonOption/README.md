# JSON Serialization

Practice converting JSON data into C# objects using `System.Text.Json`.

# What I Did
- Deserialize JSON into a DTO.
- Map DTO properties to a domain model.
- Handle nullable properties with fallback values.
- Serialize the model back into formatted JSON.
- Use `JsonNamingPolicy.SnakeCaseLower` and `[JsonPropertyName]` to map property names.
