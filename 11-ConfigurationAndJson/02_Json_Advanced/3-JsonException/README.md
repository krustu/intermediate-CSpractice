# What I Did
A simple C# project that safely parses JSON and converts it into objects.

## Features and Updates
- Parses JSON using `System.Text.Json`.
- Handles invalid JSON and parsing errors.
- Logs warnings when parsing fails.
- Converts DTOs into `Project` objects.
- Skips invalid inputs instead of stopping the program.

## Technologies
- C#
- .NET
- `System.Text.Json`

## Example
The program tests valid JSON, invalid syntax, incorrect data types, and empty input.
