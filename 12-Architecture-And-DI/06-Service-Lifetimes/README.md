# Singleton
One object instance is created and shared throughout the application's lifetime.

# Scoped
One object instance is created per scope. Adn can be used in web applications to create a new instance for each HTTP request.
(one object for per request/group) 

# Transient
new object instance is created every time it is requested. This is useful for lightweight, stateless services.
