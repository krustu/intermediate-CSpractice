# What I did
Two way to write Composition root Manually and with using DI .
Explained what is excatly difference and which one is more convinient in some case,

# What I learned
I would write the dependencies manually in a small practice or university project, 
because the composition root is short and the compiler checks everything.
I would choose the container for a large application with many classes, 
or in ASP.NET Core, because the built-in container manages lifetimes like Scoped,
and the framework already uses it.
