# NullReferenceException

## Что нужно знать

- Что такое `NullReferenceException` и почему она возникает.
- Разница между `null` и пустым объектом/коллекцией.
- Как читать `StackTrace`:
  - где произошла ошибка;
  - какой метод её вызвал;
  - как найти первопричину.
- Как использовать `ex.StackTrace` и `ex.Message`.
- Как найти проблемную строку через StackTrace и debugger.
- Как исправлять причину, а не просто скрывать exception.

## Практика

- Создать `NullReferenceException`.
- Найти причину по StackTrace.
- Исправить ошибку через проверку `null`.
- Проверить случай с пустым `List`.
- Посмотреть разницу между обработанной и необработанной ошибкой.
