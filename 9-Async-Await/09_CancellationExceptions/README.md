# CancellationToken Practice

Practiced asynchronous task cancellation in C# using `CancellationToken` and `CancellationTokenSource`.

### Key Concepts

* `async` / `await`
* `Task.Delay()` with cancellation support
* `CancellationToken.ThrowIfCancellationRequested()`
* `CancellationTokenSource.Cancel()`
* Difference between cooperative cancellation and ignoring cancellation requests
