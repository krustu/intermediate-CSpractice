# Async Tasks & IAsyncEnumerable

A C# project demonstrating asynchronous programming with `Task`, `Task.WhenAll`, `IAsyncEnumerable`, `CancellationToken`, and `Stopwatch`.

## Topics
- `async` / `await`
- `Task.Delay`
- `Task.WhenAll`
- `IAsyncEnumerable`
- `await foreach`
- `CancellationToken`
- `WithCancellation`
- Measuring execution time with `Stopwatch`
